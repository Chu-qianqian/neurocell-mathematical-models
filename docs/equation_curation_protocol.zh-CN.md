# 方程整理协议

[English](equation_curation_protocol.md) | 简体中文

## 证据门控

只有当策展人查验过合法全文、作者预印本、出版商补充材料、模型数据库条目或源代码位置，并记录了精确定位器之后，方程才可展示。仅完成书目核实不足以授权展示方程。

目录使用以下状态：

- `bibliography_verified`：标题、作者、期刊、年份和 DOI 已对照 Crossref 或其他权威元数据记录核实。
- `equation_located`：已查验包含该系统的来源并记录其定位器。
- `equation_transcribed`：展示的方程已有审计行和转录类型。
- `second_pass_checked`：展示的转录已在同一维护者工作流中完成第二次检查。
- `independently_checked`：已记录独立检查者的日期、方法、来源版本、核验来源与分歧解决情况。
- `parameters_incomplete`：方程可能已定位，但来源参数尚未完整整理。
- `full_text_unavailable`：本轮整理中无法合法查验该来源全文。
- `license_unclear`：链接的代码或数据库条目没有成文的复用评估。

`not_verified` 保留给没有进行方程级来源查验的记录。处于该状态的页面不得包含针对特定论文重构的方程。

## 整理流程

1. 通过 Crossref、PubMed、出版商元数据或等效权威记录核实书目信息。
2. 查验合法的方程来源，记录页码、章节、公式编号、补充材料、数据库或代码定位器。
3. 将变量、参数和每一条展示的方程登记到 `data/equations/` 下的 CSV 注册表。
4. 注明转录类型属于精确转录、带符号映射的等价转录还是概念性描述。模型专属已验证页面只允许前两种。
5. 显式记录未核实的输入、初始条件、边界条件、数值方法与代码许可，而不是用二手资料填补空缺。
6. 将维护者第二遍复核与独立检查分开记录。在同一工作流中重读来源不构成独立证据。
7. 提出变更前先运行本地校验器。

`equation_located` 不授权展示来源方程。展示数学式需要 `equation_transcribed` 或更强的证据、注册表覆盖以及审计行。独立复核契约定义于 [independent_review_protocol.md](independent_review_protocol.md)。

边界条件、网络条件、事件处理、外部输入、初始条件与数值积分设置各自独立审计。非空间 ODE 的边界条件为 `not_applicable` 并不意味着连接或阈值/复位规则缺失。

本仓库不存储任何 PDF、复制图表、复制表格、补充材料或第三方代码。

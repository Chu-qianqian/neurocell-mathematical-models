# 研究空白与下一步证据目标

[English](research_gaps.md) | 简体中文

当前经核实的方程集合覆盖一个电导型神经元、一个现象学脉冲神经元和一个谷氨酸调控的星形胶质细胞钙模型。它并未确立任何细胞类别的普适方程。

优先证据目标：

1. 核实 Postnov 神经元-星形胶质细胞网络的方程定位器与参数表。
2. 整理具有显式状态转移方程且来源可溯的合法微胶质细胞模型。
3. 整理具有精确分化或髓鞘化方程及参数出处的少突胶质细胞或 OPC 模型。
4. 筛查施万细胞、室管膜细胞、放射状胶质、神经干细胞、周细胞与内皮细胞的模型，不把综述或描述性论文当作方程来源。
5. 只有在来源方程与第三方许可边界都明确之后，才添加原创教学实现。
6. 为 Wilson-Cowan、Potjans-Diesmann、Montbrio-Pazo-Roxin 与 Wong-Wang 网络暂存记录审计精确的方程定位器、变量、参数与数值条件，且不导入第三方代码或论文素材。

候选记录被刻意保留在经验证的方程计数之外，直到它们满足方程门控。
